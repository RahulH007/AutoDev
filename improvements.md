# Frontend Specification: Enterprise Multi-Agent Code Orchestrator

## 1. Design Philosophy
*   **Theme:** Dark-first (Noir/Slate) with Indigo/Violet accents (e.g., Vercel/Linear aesthetic).
*   **Vibe:** Professional, high-speed, and transparent. The user should feel like they are watching an expert team work in real-time.
*   **Typography:** Inter for UI elements; JetBrains Mono for code and agent logs.

---

## 2. Tech Stack
| Category | Choice | Purpose |
| :--- | :--- | :--- |
| **Framework** | **Next.js 14+** | App Router, SSR, and built-in API routes. |
| **Styling** | **Tailwind CSS** | Rapid, consistent utility-first styling. |
| **Components** | **shadcn/ui** | Accessible, clean, and fully customizable base components. |
| **Icons** | **Lucide React** | Consistent and lightweight vector icons. |
| **State** | **Zustand** | Global UI state (sidebar toggle, current project). |
| **Data Fetching** | **TanStack Query** | Caching agent outputs and handling server states. |
| **Animations** | **Framer Motion** | Smooth transitions for the agent pipeline steps. |
| **Code Editor** | **Monaco Editor** | The same core used in VS Code for code previews. |

---

## 3. Core Pages & Layouts

### A. Global Shell (Sidebar Navigation)
*   **Navigation:** Dashboard, Projects, Templates, Team (Future), Settings.
*   **Usage Indicator:** Small progress bar showing API token usage or project limits.
*   **Theme Toggle:** Quick switch between Dark and Light modes.

### B. Dashboard (The Overview)
*   **Metrics:** Active Runs, Success Rate (%), Total Lines of Code Generated.
*   **Recent Activity:** A "Feed" style list showing: *"PM Agent completed requirements for Project X (2m ago)."*
*   **Quick Start:** A prominent "New Project" button.

### C. The Project Creation Wizard
*   **Step 1:** Name & Tech Stack selection (e.g., Next.js, FastAPI, SQL).
*   **Step 2:** Requirement Input (Rich text area with "AI Refine" button).
*   **Step 3:** LLM Configuration (Pick provider: Gemini, Groq, or Local).

### D. Workflow Runner (The "Live" View)
This is the heart of the app. It visualizes the LangGraph flow.
*   **Visual Stepper:** 
    `PM Agent ──> Architecture ──> [Approval Gate] ──> Developer ──> QA Triage ──> Final Review`
*   **Live Logs:** A terminal-style window showing the raw `print` outputs from the Python backend.
*   **Approval Panel:** When the graph hits an interrupt, show the generated PRD/Architecture side-by-side with "Approve" or "Reject & Provide Feedback" buttons.

### E. Output Viewer (Code Explorer)
*   **File Tree:** Collapsible folder structure generated by the Developer Agent.
*   **Monaco Preview:** High-quality code rendering with syntax highlighting.
*   **Artifact Downloads:** Buttons to download the PRD (PDF), Architecture (JSON), and the full Source Code (ZIP).

## 4. Feature Roadmap

### Phase 1: MVP (Development)
*   [ ] Sidebar + Dashboard Layout.
*   [ ] Project Creation Form.
*   [ ] Basic Terminal Logger for agent events.
*   [ ] Simple File List viewer.

### Phase 2: Professional (V0.0 Production)
*   [ ] Full Monaco Editor integration.
*   [ ] Animated Pipeline Stepper (Framer Motion).
*   [ ] PDF Preview for PRDs.
*   [ ] Structured User Profile & API Key management.

### Phase 3: Enterprise
*   [ ] Multi-user Authentication (Supabase Auth).
*   [ ] Collaborative project sharing.
*   [ ] "Time Travel" Debugger (stepping back through SqliteSaver checkpoints).
*   [ ] Custom Agent Configuration (edit system prompts via UI).
